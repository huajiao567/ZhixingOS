# ADR-0002：以标准化生活信号驱动可解释的自适应数字孪生

## 状态

Accepted — 2026-08-26

## 背景

知行镜需要逐步接入穿戴设备、手机使用、电脑使用和饮食记录，并让数字孪生对现实状态作细微响应。不同平台的权限、数据保留期和可用性差异很大；这些数据也属于高敏感个人数据。若让某个厂商 SDK 直接修改 Avatar，系统会产生平台耦合、不可审计推断和难以撤回的外观变化。

项目还必须避免三类误导：把单次饮食表现为长期变胖、把压力表现为心理疾病、把未实现或不可用的原生能力伪装成已连接。

## 决策

采用三段式边界：

```text
平台连接器 -> 标准化生活信号 -> 有界自适应外观 -> VRM 渲染
      |              |                    |
   明示可用性      来源/置信/确认          原因/过期/撤回
```

1. 每个连接器只负责可用性检查、系统授权、增量同步、撤回和清空；厂商原始结构不得进入渲染器。
2. 生活信号必须携带连接器、设备、发生时间、采集时间、置信度、确认状态和来源引用。原始窗口标题、URL、照片像素等默认仅在本机短暂处理。
3. 自适应外观是独立于身份和用户确认外观的临时层。熬夜可形成会衰减的眼下疲劳；压力只形成紧绷和恢复提示；单餐只形成短时饱足，长期体型变化至少需要跨日趋势或体重证据。
4. 所有效果限幅、可解释、可关闭、可清空；用户纠正优先。陈旧、低置信、候选、冲突或未来时间戳数据不产生明确外观。
5. 原生能力不可用时返回明确的 `unavailable`/`needs_setup`，不以假数据或另一能力静默替代。

## 后果

### 正面

- Android、iOS、Web、桌面伴侣和数据文件导入共享同一领域协议。
- 3D 变化可追溯到证据，且不会重写身份、性格或历史版本。
- 新连接器可独立开源、测试和替换；原始敏感数据可以留在设备侧。

### 负面

- 每个平台仍需要独立原生适配与商店权限声明；接口存在不等于真实连接已完成。
- 严格的趋势门会让体型变化慢于用户的即时期待。
- 本地聚合、衰减与去重增加了实现和测试成本。

### 中性

- 小米手环优先经 Mi Fitness 写入 Health Connect；没有该通路的地区或型号只能使用用户导出文件或后续厂商正式接口。
- 电脑数据由独立桌面伴侣或用户明确配置的 ActivityWatch 本地 API 提供，手机不能直接读取另一台电脑的本地端口。

## 备选方案

**每个 SDK 直接修改 Avatar**：拒绝。难以测试、撤回和跨平台复用。

**把一切保存为自由文本再交给大模型判断**：拒绝。来源、单位、时间窗口和安全边界不可验证。

**单次输入立即永久改变体型/性格**：拒绝。会混淆瞬时状态、身体趋势和身份特质。

## 非功能要求

- 本地推导目标耗时小于 20 ms/2000 条近期信号，不阻塞 3D 帧循环。
- 单连接器失败不破坏已有数据；游标同步必须幂等。
- 原始敏感内容默认不上传；服务端密钥不得进入 `EXPO_PUBLIC_*`。
- 所有新来源纳入导出、撤回、按来源删除和审计。
